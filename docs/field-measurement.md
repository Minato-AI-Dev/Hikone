# 現地歩行計測・実証ログの運用
## 移動時間の実測
- 対象は NODE 間の徒歩移動。途中の信号待ち、横断、階段を含める。
- 始点・終点の位置を明記し、計測日時・計測者・距離・実測分数・天候・経路を記録する。
- 余裕時間は実測値に混ぜない。観光客向け余裕は推薦ロジック側で別に加算する。
- 実測済みの区間だけ `src/data/measuredWalking.ts` へ追加する。status='現地実測'、policy='実測済' とする。
- 同一 NODE 組の机上概算 EDGE より実測を優先する。未登録の区間は推測して追加しない。
- 駐車場 PK01〜PK04 からは現状、実測 EDGE 未登録のため推薦が出ない場合がある。
## 実証ログ
- 利用者がホームの同意チェックを有効にした場合のみ、匿名の画面イベントが端末の localStorage に保存される。
- 自由記述、GPS座標などは保存せず、識別情報を付けない。
- 利用者が「調査ログをCSVで保存する」を押した場合のみ、端末へCSVをダウンロードする。
- サーバーへの自動送信は未実装。複数人の集計には、同意を得てCSVを回収する別の手順が必要。
- 同意を解除すると当該端末の記録は消去される。共有端末の場合は個人情報を入力させない。
