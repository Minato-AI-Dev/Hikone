# 徒歩時間の自動推定
- プルリクエストの変更は公開サーバーで `GOOGLE_MAPS_API_KEY` を設定し、Google Maps Platform の Routes API を有効化すると動作します。GitHub PagesのみではサーバーAPIは利用できません。
- API呼び出しはサーバー側から行い、秘密鍵をブラウザに公開しません。1回の検索で最大17区間の計算が発生します。共有レート制限ストアが未設定・障害時は課金APIを停止します。Googleのクォータも設定してください。
- 出発・経由・帰着地点は彦根市内の地名テキストで指定します。住所の曖昧さにより別の地点へ案内される可能性があり、最終的には各地点を座標またはPlace IDへ置き換える必要があります。
- 基本所要時間はGoogle Routes APIの徒歩時間を使用します。歩く速さの係数は 普通1.0・ゆっくり1.2・休憩しながら1.45、状況は 通常1.0・雨1.15・暑さ1.25。係数は仮説であり、統計的保証はありません。
- 地図APIの推定徒歩時間 × 歩行係数 × 天候係数 + 最低滞在時間 + 固定安全余裕5分で所要時間を算出します。
- GPS取得位置は現在、地図アプリへのナビ用であり徒歩時間APIには送信しません。現在地の誤差・個人情報を考慮し、選択地点からの予測を使用します。
- 地図APIの応答が得られない場合は実測のみの経路を使用し、揃わない場合は時間成立候補を表示しません。仮値は明示的なローカルデモモードのみです。
- 豪雨・荒天で歩行そのものが危険な場合は係数で補正するのではなく、運用側で停止する設計が必要です。
- 追加の滞在時間（飲食の待ち時間、長時間の休憩など）は現在の最低ACTION時間だけでは表現できません。今後の改修対象です。

公開・設定・検証手順は[production-routing.md](production-routing.md)を参照してください。
