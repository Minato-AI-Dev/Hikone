# 次の彦根：完全版（開発ブランチ）

このブランチ feat/hikone-full-version は、現行の公開版 main を変更せず、既存機能を統合するための開発用コピーです。名称は目標であり、現段階の完全性を保証するものではありません。

## 今回つないだ機能
- 6問の徒歩ルート推薦と、実時間が確認できない経路を推薦しない設計
- 自然文によるAI相談（クラウド未設定時は限定的なローカル解釈）
- 観光地・店舗・映画ロケ地を含む行き先検索（未検証候補を区別）
- 端末に保存した訪問履歴の閲覧（訪問は本人の自己申告）
- PR #29のGoogle Places営業情報照会。店舗IDが未確認ならunknownを返す
- 調査への協力は引き続き任意

## 完成までの受入基準
| 項目 | 現状 | 正式公開前に必要なこと |
| --- | --- | --- |
| 徒歩経路 | Google Maps推定値、実測データなし | 入口照合、代表3ルートの実地歩行と遅延時試験 |
| 店舗営業情報 | 3店舗のAPIコード・未登録のPlace ID | 公式名称・住所でPlace ID照合、APIキー制限、課金と定休日検証 |
| 店舗体験 | 滞在時間・予約可否・個別入口が不明 | 各店舗の確認・同意、時間と予約条件の実測 |
| AI | クラウド任意、ローカル解釈へフォールバック | 個人情報入力抑止と誤推薦・費用の実機試験 |
| 訪問履歴 | 端末内保存の自己申告 | 再訪時の履歴復元と削除・データ保護方針の確認 |
| QR | コンポーネントのみ、現地QR未設置 | 現地の設置許可と不正チェックイン防止。未確認のため非表示 |
| 調査 | 匿名イベント件数の同意制集計 | 同意撤回・保存期限・倫理面・効果指標の確認 |
| 運用 | 技術的に公開可能なUI | 実機試験、監視、問い合わせ、外部API規約確認 |

## 注意
- ブランチは別リポジトリではありません。完全に独立したリポジトリの作成はGitHub上で別途必要です。
- main、GitHub Pagesの本番公開、既存の研究データはこの段階では変更しません。
- CI成功は本番APIと実際の徒歩行動の安全性を保証しません。
- 外部AIへの自由入力は外部サービス送信となる場合があるため、個人情報を書かないよう案内しています。
